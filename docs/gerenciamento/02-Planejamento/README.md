# 2. Planejamento

Este grupo de processos é exigido para estabelecer o escopo do projeto, refinar os objetivos e definir o curso de ação necessário para alcançar os objetivos.

## Mapeamento das Áreas de Conhecimento
- **Integração**: Desenvolver o plano de gerenciamento do projeto.
- **Escopo**: Planejar o gerenciamento, Coletar requisitos, Definir escopo, Criar EAP (WBS).
- **Cronograma**: Planejar o gerenciamento, Definir atividades, Sequenciar atividades, Estimar durações, Desenvolver cronograma.
- **Custos**: Planejar o gerenciamento, Estimar custos, Determinar orçamento.
- **Qualidade**: Planejar o gerenciamento da qualidade.
- **Recursos**: Planejar o gerenciamento, Estimar recursos das atividades.
- **Comunicações**: Planejar o gerenciamento das comunicações.
- **Riscos**: Planejar o gerenciamento, Identificar riscos, Realizar análises qualitativa e quantitativa, Planejar respostas aos riscos.
- **Aquisições**: Planejar o gerenciamento das aquisições.
- **Partes Interessadas**: Planejar o engajamento das partes interessadas.
