# 3. Execução

Este grupo de processos é realizado para concluir o trabalho definido no plano de gerenciamento do projeto para satisfazer as especificações do mesmo.

## Mapeamento das Áreas de Conhecimento
- **Integração**: Orientar e gerenciar o trabalho do projeto, Gerenciar o conhecimento do projeto.
- **Qualidade**: Gerenciar a qualidade.
- **Recursos**: Adquirir recursos, Desenvolver a equipe, Gerenciar a equipe.
- **Comunicações**: Gerenciar as comunicações.
- **Riscos**: Implementar respostas aos riscos.
- **Aquisições**: Conduzir as aquisições.
- **Partes Interessadas**: Gerenciar o engajamento das partes interessadas.
